# 🎯 English Kid - 儿童AI口语练习系统

一个完全基于Think教材体系的儿童英语口语练习网站，通过故事+对话的形式，让孩子自然开口说英语。

## ✨ 核心功能

### 1. 六大级别体系
- **Pre Think** - 启蒙级，最简单的句型
- **Think 1** - 基础级
- **Think 2** - 进阶级
- **Think 3** - 提高级
- **Think 4** - 高级
- **Think 5** - 精通级

### 2. 完整学习流程

每个单元包含：

1. **📚 本课单词** - 图片 + 发音 + 中文释义
2. **💬 核心句型** - 简单、短句、儿童友好
3. **📖 情景小故事** - 有趣易懂的情节
4. **🤖 AI口语对话** - 核心练习环节
5. **📊 智能数据分析** - 学习报告与薄弱点分析

### 3. AI对话特色

- ✅ AI主动发起对话
- ✅ 使用本课词汇和句型
- ✅ 鼓励式反馈，不批评
- ✅ **沉默5秒自动引导** - 给出选项式疑问句
  - 例如："What's your favorite fruit? Apple, banana, or strawberry?"
  - 例如："Do you like dogs? Yes or no?"

### 4. 智能数据分析

系统自动记录：
- 孩子不会回答的句子
- 沉默时间长的题目
- 重复出错的句型

生成：
- 本课薄弱点清单
- 表现好的部分标注"已掌握"
- 薄弱部分标注"需加强"

### 5. 艾宾浩斯记忆复习 ⭐

**全自动复习系统**：

- ✅ 自动记录薄弱内容
- ✅ 按记忆曲线推送复习：
  - 当天复习
  - 第2天复习
  - 第5天复习
  - 第7天复习
  - 第14天最后巩固
- ✅ 下次登录自动弹出复习任务
- ✅ 无需家长操作，全自动安排

## 🚀 快速开始

### 方法一：直接打开（推荐）

1. 双击 `index.html` 文件
2. 在浏览器中打开（推荐使用Chrome）
3. 开始学习！

### 方法二：本地服务器

```bash
# 如果你有Python
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

然后访问 `http://localhost:8000`

## 🎮 使用说明

### 1. 选择级别
在首页点击适合的级别卡片（Pre Think 到 Think 5）

### 2. 选择单元
在级别页面选择要学习的单元

### 3. 学习流程

**步骤1：本课单词**
- 查看单词的emoji图标、英文拼写、中文释义
- 点击单词卡片可朗读发音

**步骤2：核心句型**
- 学习本课的核心句型
- 点击句子可听发音

**步骤3：情景故事**
- 阅读有趣的情景小故事
- 点击故事可自动朗读

**步骤4：AI对话练习** 🎤
- AI会主动发起对话
- 点击"🎤 点击说话"按钮进行语音回答
- 或者点击屏幕上的选项按钮快速回答
- 如果5秒没有回答，AI会给出提示和选项

**步骤5：学习报告**
- 查看本课表现
- 了解需要加强的部分
- 系统会自动安排复习

### 4. 自动复习

- 完成学习后，系统会自动记录薄弱点
- 按艾宾浩斯记忆曲线安排复习
- 下次打开网站时会自动提醒复习
- 点击"开始复习"即可复习薄弱知识点

## 🔧 自定义扩展

### 添加新单元

在 `app.js` 文件中的 `courseData` 对象中添加新单元：

```javascript
{
    id: 2, // 单元编号
    name: 'Unit 2: 单元名称',
    words: [
        { word: 'apple', chinese: '苹果', emoji: '🍎' },
        // 更多单词...
    ],
    sentences: [
        'I like apples. 我喜欢苹果。',
        // 更多句型...
    ],
    story: {
        title: '故事标题',
        content: '故事内容...',
        emoji: '📖'
    },
    conversations: [
        { ai: 'Do you like apples?', options: ['Yes', 'No'] },
        // 更多对话...
    ]
}
```

### 对话类型说明

- `type: 'open'` - 开放式问题
- `type: 'repeat'` - 跟读练习
- `options: ['选项1', '选项2']` - 选择题
